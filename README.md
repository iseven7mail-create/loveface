## 網頁部署

這是純靜態網站，沒有安裝或建置步驟。將所有檔案連同 `assets` 資料夾放在同一個網站根目錄，即可開啟 `index.html`。

在 GitHub 專案的 **Settings → Pages** 選擇 **Deploy from a branch**，來源設為 **main / (root)** 並儲存，即可發佈 GitHub Pages。
